# Third-party notices

lumberroom is licensed under Apache-2.0; the full text sits in `LICENSE` at the repository root. This
file covers the components lumberroom redistributes rather than owns: one model, baked into `/models` at
build time, and the crates in the dependency tree whose licenses require attribution.

## Model weights

The runtime image bakes in weights for the default embedding model, fetched at build time and
never downloaded again at runtime (`docs/rust-spike-findings.md` covers why: a first-request
download on a VM with restricted egress is a silent failure that looks like a hung tool call).

- **Model:** `Qdrant/bge-base-en-v1.5-onnx-Q`, an ONNX quantization of `BAAI/bge-base-en-v1.5`.
- **Source:** https://huggingface.co/Qdrant/bge-base-en-v1.5-onnx-Q, derived from
  https://huggingface.co/BAAI/bge-base-en-v1.5.
- **License:** Apache-2.0.

Verified against the built image (`docker run --rm --entrypoint ls lumberroom-server:0.1.0 -R /models`), which
shows the cache under `models--Qdrant--bge-base-en-v1.5-onnx-Q`, holding `model_optimized.onnx`
and its tokenizer files.

## Full dependency license set

every package in `Cargo.lock` against its published license on crates.io. That file is the
